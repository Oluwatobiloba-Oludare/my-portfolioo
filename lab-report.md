Brief Reflection

What was challenging?

One of the main challenges was understanding how local and remote branches relate to each other, especially when my local repository showed master while the remote repository used main. It was also initially confusing managing branches, deleting them safely, and understanding when to use commands like git fetch versus git pull. Getting comfortable with staging, committing, and pushing changes in the correct order required practice.

How does Git help in DevOps teams?

Git helps DevOps teams collaborate efficiently by enabling version control, safe experimentation through branches, and clear tracking of changes. Multiple team members can work on the same project without overwriting each other’s work.

Any issues faced and how I resolved it?

I encountered issues such as not seeing any branch after cloning a repository and authorization errors when pushing to remote repositories. I resolved these by confirming I was in the correct project directory, understanding repository states, and properly configuring authentication using access tokens. Through troubleshooting and practice, I became more confident using Git commands and resolving common version control problems.
